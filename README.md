
# AI Password Security Advisor 🔐

## About
A beginner-friendly cybersecurity project using Python
and Prompt Engineering to analyze password characteristics.

## Features
- Password length checking
- Uppercase and lowercase checking
- Number detection
- Special character detection
- Basic password scoring
- Weakness identification
- Structured AI prompt generation
- Security recommendations

## Technologies
- Python
- Regular Expressions
- Prompt Engineering
- VS Code
- Git and GitHub

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

python main.py

## Project Files

- main.py — Main application
- password_analyzer.py — Password analysis module
- prompt_engine.py — Prompt generation module

## Disclaimer

This project is for educational purposes only.
Never enter your actual personal passwords.
The scoring method is a basic demonstration.
